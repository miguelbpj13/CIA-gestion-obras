## Reglas de trabajo

- Cada entrega es un pull request desde una rama propia; nunca push directo a `main`.
- Cada integrante hace al menos un commit propio por sesión, bajo su usuario.
- Nadie aprueba su propio pull request: otro integrante lo revisa y comenta antes de fusionar.
- `CONTRIBUCIONES.md` se actualiza cada sesión.
